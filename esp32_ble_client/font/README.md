# Font Assets

This folder contains generated font header files for the ESP32 e-paper client.

The font is used for this project is Google Sans Flex:

https://fonts.google.com/specimen/Google+Sans+Flex?preview.script=Latn

License information for bundled font assets is provided in OFL.txt.

The font conversion script `epdiy/scripts/fontconvert.py` used to generate these headers comes from the EPDiy project:

https://github.com/vroland/epdiy

Note: After running fontconvert.py, update the generated font header files to use the data types required by this project.
